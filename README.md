# C1Profiles

CAM post processors for the CubiFab C1 CNC machine, organized by CAM application.

## Directory Index

[`CAM_PostProcessors/`](CAM_PostProcessors/) contains the available post processor packages. Open the guide for your CAM application for installation and usage instructions.

| CAM application | Folder and user guide | Supported configuration |
| --- | --- | --- |
| Autodesk Fusion (Fusion 360) | [Fusion360-profiles](CAM_PostProcessors/Fusion360-profiles/README.md) | Three-axis milling. |
| Siemens NX (UG) | [Siemens.NX-profiles](CAM_PostProcessors/Siemens.NX-profiles/README.md) | Three-axis milling and four-axis milling with an A-axis rotary axis. |
