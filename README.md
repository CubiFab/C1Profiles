# C1Profiles
CubiFab C1 CNC post processors and  machine/tool settings for different CAM software 


----

# Autodesk Fusion (Fusion 360)

## Install PostProcessor

1. Start Autodesk Fusion.

2. Navigate to the Manufacture Workspace.

3. Under the Manage group, select the Post Library button.

4. Navigate to the "My Posts->Local" folder.

5. Click the "Import" button.

6. Select the "C1Profiles\CAM_PostProcessors\Fusion360-profiles\CubifabC1.cps" file and import.



## Using Cubifab C1 Profiles

When doing post process, select the Cubifab C1 machine and the `CubifabC1.cps` post file.

Note: This post file only support 3 axis currently.



Other CAM software postprocessors will be support soon and update here.
